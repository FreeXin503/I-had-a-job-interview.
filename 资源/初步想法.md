微信小程序开发
1.项目简介
    这是一个AI模拟面试的项目，面试完成后给予评分。
2.详细功能
    面试准备：
        （1）选择面试官风格：随机、温和、标准、压力
        （2）选择面试岗位
        （3）个人简历上传界面，能够识别简历的内容（上传格式为pdf）
        （4）面试时间，可以选择5分钟，10分钟，和15分钟，20分钟（可以根据用户的回答水平，适当延长时间和缩减时间）
    面试阶段：
        （1）考官提问，客户回答，一对一对答。
        （2）用户回答使用录音转文字的方式，说完后，点击我已经读完按钮，即可发送给面试官，说话不可撤回，模拟真实场景。
    评分阶段：
        （1）对刚刚的面试进行打分，1-100分之间，90-100分为优秀，80-90分为良好，60-80分为几个，60分以下为不及格。
        （2）可以将报告保存下来，保存文件格式为pdf。
3.使用的框架
    -- 前端：微信小程序原生框架 (TypeScript + Less/Sass)
    -- 后端：Node.js + NestJS
    -- 数据库：MySQL（连接名：localhost_3306，数据库：ai_interview，用户：root，密码：123456）
    -- Agent端：推荐首选：LangGraph (Python/TypeScript)，
        这是我deepseek的API，sk-12117c0cd5154356a3518f50a28137d7，使用后端参数选择deepseek-v4-pro模型
    （1）语音与大模型管线
        ① TTS 引擎选型： 字节火山引擎（语音合成）或 微软 Azure TTS。必须选择支持流式输入、流式输出（Chunked Audio）的商业 API。
        ② 大模型对接： 直接使用官方或标准 OpenAI SDK（将 BaseURL 指向 DeepSeek），开启 stream: true。
    （2）缓存与状态机：Redis
        ① 用于存储第二关“地狱大乱斗”中用户的实时面试上下文、多轮追问的 Prompt 历史，以及微信群“求助/代答”的临时房间状态。
        ② 持久化数据库：MySQL / PostgreSQL
        用于存储用户的简历解析结果、生成的“潜台词解密画布”历史记录
    （3）Agent 端技术栈清单组件
        | 组件 | 推荐选型 | 说明 |
        |------|----------|------|
        | Agent编排框架 | LangGraph(Python) | 支撑复杂的追问/跳题状态机，图结构控制最稳健 |
        | 大模型接口层 | OpenAlSDK/DeepSeek 官方API | 开启stream=true，过滤 `<think>` 标签 |
        | 向量数据库（RAG） | Milvus/Chroma/Pinecone | 用于瞬时解析和检索用户的PDF简历关键点 |
        | 记忆与状态存储 | Redis | 存储Session级别的对话上下文与Agent状态 |
        | 异步任务队列 | Celery(Python) | 用于面试结束后，异步生成“潜台词解密画布” |
