## ❓ 快速排查

### Agent无法启动
```bash
cd agent
venv\Scripts\activate
pip install -r requirements.txt
```

### 后端无法启动
```bash
cd backEnd
npm install
检查 .env 配置
确认MySQL已启动
```

### 前端编译错误
```
清除缓存
重新编译
查看控制台错误
```
