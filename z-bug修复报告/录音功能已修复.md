## 📊 录音流程

```
用户按住"按住说话" 
  ↓
检查录音权限
  ↓
开始录音（显示波形）
  ↓
用户松开按钮
  ↓
停止录音
  ↓
上传到后端
  ↓
语音识别
  ↓
显示识别文字
  ↓
获取AI回复
  ↓
显示AI问题
```

## 🎯 需要的后端API

### 1. 上传录音
```
POST /api/interview/upload-audio
参数：audio文件, interviewId, duration
返回：audioUrl
```

### 2. 语音识别
```
POST /api/interview/recognize
参数：audioUrl, interviewId
返回：识别的文字
```

### 3. 获取AI回复
```
POST /api/interview/next-question
参数：interviewId, userAnswer
返回：AI的下一个问题
```

## 🐛 常见问题

### Q1: 录音没有声音？
**A**: 检查麦克风权限，确保已授权

### Q2: 上传失败？
**A**: 
- 确保后端服务已启动
- 开启小程序调试模式
- 或配置合法域名（HTTPS）

### Q3: 识别不准确？
**A**: 
- 在安静环境录音
- 清晰地说话
- 靠近麦克风

### Q4: 显示"后端未连接"？
**A**: 
- 启动后端服务
- 开启调试模式
- 或使用模拟数据体验流程
