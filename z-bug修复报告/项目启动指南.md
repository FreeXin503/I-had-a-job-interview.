## ❓ 常见问题

### 1. Agent服务启动失败

**问题：** `ModuleNotFoundError: No module named 'fastapi'`

**解决：**
```bash
cd agent
venv\Scripts\activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 2. 后端服务启动失败

**问题：** `Cannot find module '@nestjs/core'`

**解决：**
```bash
cd backEnd
npm install
```

---

### 3. 端口被占用

**问题：** `Error: listen EADDRINUSE: address already in use :::3000`

**解决方案1：** 关闭占用端口的程序
```bash
# 查看占用端口的进程
netstat -ano | findstr :3000

# 结束进程（替换PID为实际进程ID）
taskkill /PID <PID> /F
```

**解决方案2：** 修改端口
- Agent：修改 `agent\.env` 中的 `PORT=8001`
- 后端：修改 `backEnd\.env` 中的 `PORT=3001`

---

### 4. 数据库连接失败

**问题：** `ER_ACCESS_DENIED_ERROR: Access denied for user 'root'@'localhost'`

**解决：**
1. 确认MySQL服务已启动
2. 确认用户名密码正确
3. 修改 `backEnd\.env` 中的数据库配置

---

### 5. 微信小程序编译错误

**问题：** 页面无法打开或白屏

**解决：**
1. 检查 `app.json` 配置是否正确
2. 确认所有页面的 `.json` 文件存在
3. 清除缓存后重新编译
4. 查看控制台错误信息

---

### 6. 录音功能不可用

**说明：** 
- 开发者工具中的录音与真机不同
- 开发者工具使用模拟数据演示流程
- 真机测试需要配置合法域名和HTTPS

**解决：**
- 开发阶段：使用模拟数据测试
- 生产环境：配置服务器域名和SSL证书
