# 面了个试 - 启动说明

## 项目启动步骤

### 1. 数据库准备

```sql
-- 创建数据库
CREATE DATABASE ai_interview CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2. 后端启动

```bash
# 进入后端目录
cd backEnd

# 安装依赖
npm install

# 启动开发服务器
npm run start:dev
```

后端服务将运行在 `http://localhost:3000`

### 3. Agent启动

```bash
# 进入Agent目录
cd agent

# 创建虚拟环境（首次）
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动Agent服务
python main.py
```

Agent服务将运行在 `http://localhost:8000`

### 4. 前端启动

1. 使用微信开发者工具打开 `frontEnd` 目录
2. 配置AppID（测试号或正式AppID）
3. 点击编译运行

## 环境要求

- Node.js >= 16.0.0
- Python >= 3.10
- MySQL >= 8.0
- Redis >= 6.0（可选）

## 常见问题

### 1. 数据库连接失败

检查MySQL服务是否启动，用户名密码是否正确。

### 2. Agent服务启动失败

确保Python版本 >= 3.10，检查依赖是否完整安装。

### 3. 前端无法连接后端

检查后端服务是否启动，API地址配置是否正确。

### 4. 语音功能无法使用

语音录制需要在真机上测试，模拟器不支持。
