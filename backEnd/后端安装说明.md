# 后端安装说明

## 📦 安装依赖

### 方式一：使用批处理文件（推荐）

双击运行：
```
启动后端.bat
```

批处理文件会自动检查并安装依赖。

---

### 方式二：手动安装

```bash
cd backEnd
npm install
```

**注意：** 安装过程可能需要5-10分钟，请耐心等待。

---

## ⚠️ 常见警告（可忽略）

安装过程中可能会看到以下警告，这些都是正常的：

```
npm warn deprecated inflight@1.0.6
npm warn deprecated glob@7.2.3
npm warn deprecated eslint@8.57.1
npm warn deprecated multer@1.4.5-lts.2
```

这些是依赖包的版本警告，不影响项目运行。

---

## ✅ 安装成功标志

看到以下输出表示安装成功：

```
added XXX packages in XXs
```

或者检查 `node_modules` 文件夹是否存在：

```bash
dir node_modules
```

---

## 🚀 启动服务

### 开发模式（推荐）

```bash
npm run start:dev
```

服务会自动监听文件变化并重启。

### 生产模式

```bash
# 先编译
npm run build

# 再启动
npm run start:prod
```

---

## 🔍 验证安装

### 1. 检查依赖

```bash
npm list --depth=0
```

应该看到所有主要依赖包。

### 2. 检查NestJS CLI

```bash
npx nest --version
```

应该显示版本号（如 10.x.x）。

### 3. 尝试编译

```bash
npm run build
```

如果编译成功，说明依赖安装正确。

## 🗄️ 数据库准备

在启动服务前，确保MySQL已创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS ai_interview 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
```

## ❌ 常见错误

### 1. 端口被占用

**错误：** `Error: listen EADDRINUSE: address already in use :::3000`

**解决：**
```bash
# 查找占用端口的进程
netstat -ano | findstr :3000

# 结束进程
taskkill /PID <进程ID> /F
```

或修改 `.env` 中的端口：
```env
PORT=3001
```

---

### 2. 数据库连接失败

**错误：** `ER_ACCESS_DENIED_ERROR` 或 `ECONNREFUSED`

**解决：**
1. 确认MySQL服务已启动
2. 确认数据库已创建
3. 确认用户名密码正确
4. 检查 `.env` 配置

---

### 3. 模块未找到

**错误：** `Cannot find module '@nestjs/core'`

**解决：**
```bash
# 删除 node_modules 和 package-lock.json
rmdir /s /q node_modules
del package-lock.json

# 重新安装
npm install
```

---

### 4. TypeScript编译错误

**错误：** `TS2307: Cannot find module` 或其他TS错误

**解决：**
```bash
# 清理编译缓存
rmdir /s /q dist

# 重新编译
npm run build
```

---

## 🔄 重新安装

如果遇到无法解决的问题，可以完全重新安装：

```bash
# 1. 删除依赖和缓存
rmdir /s /q node_modules
del package-lock.json

# 2. 清理npm缓存
npm cache clean --force

# 3. 重新安装
npm install

# 4. 启动服务
npm run start:dev
```
