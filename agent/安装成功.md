## 常见问题

### 1. 端口被占用
如果8000端口被占用，修改 `.env` 文件：
```
PORT=8001
```

### 2. DeepSeek API密钥
如需更换API密钥，修改 `.env` 文件：
```
DEEPSEEK_API_KEY=your_new_key
```

### 3. 停止服务
在命令行窗口按 `Ctrl+C`
