# Agent端快速安装指南

## 问题说明

原始的 `requirements.txt` 包含了一些需要编译的包（如 langgraph），在Windows环境下可能遇到Rust编译问题。

## 解决方案

已简化依赖，移除了需要编译的包，改用纯Python实现。

## 安装步骤

### 1. 确保Python环境
```bash
python --version  # 应该是 3.10 或更高版本
```

### 2. 创建虚拟环境
```bash
cd agent
python -m venv venv
```

### 3. 激活虚拟环境
```bash
# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

### 4. 升级pip（可选但推荐）
```bash
python -m pip install --upgrade pip
```

### 5. 安装依赖
```bash
pip install -r requirements.txt
```

如果还是遇到问题，可以逐个安装：
```bash
pip install fastapi==0.104.1
pip install uvicorn==0.24.0
pip install python-multipart==0.0.6
pip install openai==1.3.0
pip install pydantic==2.5.0
pip install python-dotenv==1.0.0
pip install PyPDF2==3.0.1
pip install python-docx==1.1.0
pip install httpx==0.25.2
pip install requests==2.31.0
pip install tenacity==8.2.3
```

### 6. 验证安装
```bash
python -c "import fastapi; print('FastAPI安装成功')"
python -c "import openai; print('OpenAI安装成功')"
```

### 7. 启动服务
```bash
python main.py
```

应该看到：
```
🚀 AI Agent 服务启动在端口 8000
INFO:     Started server process
INFO:     Uvicorn running on http://0.0.0.0:8000
```

## 常见问题

### 1. 网络问题
如果下载速度慢，可以使用国内镜像：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 权限问题
如果遇到权限错误，使用：
```bash
pip install --user -r requirements.txt
```

### 3. 依赖冲突
如果遇到版本冲突，可以尝试：
```bash
pip install --upgrade --force-reinstall -r requirements.txt
```

### 4. 虚拟环境问题
如果虚拟环境有问题，删除重建：
```bash
# 删除虚拟环境
rm -rf venv  # Linux/Mac
rmdir /s venv  # Windows

# 重新创建
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 技术变更说明

### 移除的包
- ❌ `langchain` - 太重，依赖复杂
- ❌ `langchain-openai` - 不必要
- ❌ `langgraph` - 需要Rust编译
- ❌ `redis` - 暂时不需要
- ❌ `hiredis` - 需要编译
- ❌ `aiohttp` - 用httpx替代
- ❌ `pdfplumber` - 需要编译，用PyPDF2替代

### 保留的核心包
- ✅ `fastapi` - Web框架
- ✅ `uvicorn` - ASGI服务器
- ✅ `openai` - DeepSeek API客户端
- ✅ `pydantic` - 数据验证
- ✅ `PyPDF2` - PDF解析
- ✅ `python-docx` - Word解析
- ✅ `httpx` - HTTP客户端

### 代码调整
- 使用 `openai.OpenAI` 客户端直接调用DeepSeek API
- 移除了LangChain的抽象层
- 简化了异步调用逻辑
