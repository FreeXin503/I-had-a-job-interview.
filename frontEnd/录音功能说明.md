# 录音功能说明

## 开发者工具 vs 真机

### 开发者工具
- ✅ 可以录音
- ⚠️ 录音格式与真机不同
- ⚠️ 只能在工具上播放调试
- ⚠️ 无法直接在客户端播放

### 真机测试
- ✅ 完整的录音功能
- ✅ 标准的音频格式
- ✅ 可以正常播放和上传
- ✅ 支持语音识别

## 当前实现

### 模拟模式（开发者工具）
1. 按住录音按钮开始录音
2. 松开按钮结束录音
3. 自动显示模拟的识别文本
4. AI自动回复下一个问题

### 真机模式（需要后端支持）
1. 录音 → 上传到服务器
2. 服务器调用语音识别API
3. 返回识别文本
4. 提交给AI生成回复

## 测试建议

### 在开发者工具中
- 可以测试UI和交互流程
- 录音功能会有提示说明
- 使用模拟数据演示完整流程

### 在真机上
- 需要授权麦克风权限
- 需要启动后端服务
- 可以测试完整的语音交互

## 权限配置

在 `app.json` 中已配置（如需真机测试）：

```json
{
  "permission": {
    "scope.record": {
      "desc": "需要使用你的麦克风进行语音录制"
    }
  }
}
```
