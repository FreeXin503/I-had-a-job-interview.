## 🔧 API接口说明

### 1. 上传录音文件

**接口**：`POST /api/interview/upload-audio`

**参数**：
- `audio`：录音文件（multipart/form-data）
- `interviewId`：面试ID
- `duration`：录音时长（毫秒）

**返回**：
```json
{
  "audioUrl": "https://your-domain.com/uploads/audio/xxx.mp3",
  "duration": 5000
}
```

---

### 2. 语音识别

**接口**：`POST /api/interview/recognize`

**参数**：
```json
{
  "audioUrl": "https://your-domain.com/uploads/audio/xxx.mp3",
  "interviewId": "test"
}
```

**返回**：
```json
{
  "text": "我是一名应届毕业生，主修计算机科学。"
}
```

---

### 3. 获取AI回复

**接口**：`POST /api/interview/next-question`

**参数**：
```json
{
  "interviewId": "test",
  "userAnswer": "我是一名应届毕业生，主修计算机科学。"
}
```

**返回**：
```json
{
  "question": "很好，请介绍一下你做过的项目经验。"
}
```

## 🐛 常见问题

### 1. 录音没有声音

**原因**：
- 麦克风权限未授权
- 手机静音
- 录音时间太短

**解决**：
- 检查权限设置
- 关闭静音模式
- 说话时间超过0.5秒

---

### 2. 上传失败

**原因**：
- 后端未启动
- 网络连接问题
- 域名未配置

**解决**：
- 启动后端服务
- 检查网络连接
- 配置合法域名或开启调试模式

---

### 3. 识别不准确

**原因**：
- 环境噪音大
- 说话不清晰
- 录音质量差

**解决**：
- 在安静环境录音
- 清晰地说话
- 靠近麦克风

---

### 4. 显示"后端未连接"

**原因**：
- 后端服务未启动
- API地址错误
- 网络不通

**解决**：
- 启动后端服务
- 检查API地址配置
- 开启调试模式

## 📝 代码修改说明

### 修改的文件
- `pages/interview/interview.js`

### 主要修改

#### 1. 去掉弹窗
```javascript
// 修改前
initInterview() {
  wx.showModal({
    title: '录音功能说明',
    content: '...',
    success: () => {
      // 初始化
    }
  });
}

// 修改后
initInterview() {
  // 直接初始化，不显示弹窗
  this.setData({
    currentQuestion: { text: '...' }
  });
  this.startTimer();
}
```

#### 2. 完善录音参数
```javascript
recorderManager.start({
  duration: 60000,      // 最长60秒
  sampleRate: 16000,    // 采样率
  numberOfChannels: 1,  // 单声道
  encodeBitRate: 48000, // 比特率
  format: 'mp3',        // MP3格式
  frameSize: 10         // 帧大小
});
```

#### 3. 添加错误处理
```javascript
recorderManager.onError((err) => {
  console.error('录音错误', err);
  wx.showToast({
    title: '录音出错：' + err.errMsg,
    icon: 'none'
  });
});
```

#### 4. 实现上传和识别
```javascript
// 上传录音
wx.uploadFile({
  url: 'http://localhost:3000/api/interview/upload-audio',
  filePath: tempFilePath,
  name: 'audio',
  success: (res) => {
    // 调用识别API
    this.recognizeSpeech(audioUrl);
  }
});

// 语音识别
wx.request({
  url: 'http://localhost:3000/api/interview/recognize',
  method: 'POST',
  data: { audioUrl: audioUrl },
  success: (res) => {
    // 显示识别结果
    this.addDialogue('user', res.data.text);
    // 获取AI回复
    this.getAIResponse(res.data.text);
  }
});
```
